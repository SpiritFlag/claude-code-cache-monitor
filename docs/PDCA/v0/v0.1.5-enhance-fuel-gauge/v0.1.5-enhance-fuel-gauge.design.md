### 1.2 갈림길 상세

#### D-1 FR-6의 "오늘"의 범위

| 선택지 | 내용 | 대가 |
|---|---|---|
| a | 폴더 전체의 오늘 — `ROOT` 아래 모든 세션의 오늘 키 합 | 선택 세션과 무관한 값이 세션 카드 안에 놓인다. 세션을 바꿔도 이 칸은 안 바뀐다 |
| b | 선택 세션의 오늘분 — 그 세션의 오늘 키 값 | 하루 안에 끝나는 세션에서 FR-12의 세션 칸과 같은 값이 되어 세 칸 중 둘이 겹친다. 폴더 값과 나란히 놓을 이유가 사라진다 |

**추천**: a. plan §1이 요구하는 비교 축은 "지금 세션 → 오늘 → 평소"이고 셋이 서로 다른 범위여야 성립한다. b는 대부분의 세션에서 세션 칸과 값이 같아져 칸 하나를 낭비한다.

#### D-2 연비 세 값의 표시 형태

| 선택지 | 내용 | 대가 |
|---|---|---|
| a | `.whatif` 3칸 그리드 재사용 — `modelCard`가 비운 자리와 CSS를 그대로 이어받는다 | 칸이 좁아 오늘 칸에 활성시간과 총액을 한 줄에 눌러 담아야 한다 |
| b | `.sub` 텍스트 줄 3개를 세로로 쌓는다 | "나란히 놓고 비교한다"는 목적이 약해진다. 세 값을 눈으로 견주기 어렵다 |

**추천**: a. 세 값을 나란히 견주는 것이 이 사이클의 목적이라 그리드가 형태와 목적이 맞고, `.whatif` CSS와 좁은 화면 규칙(§2.2 제외로 그대로 두기로 한 것)의 근거가 함께 살아남는다.

#### D-3 새 세션 원칙 문구

| 선택지 | 내용 | 대가 |
|---|---|---|
| a | `세션 안에서 모델을 바꾸지 않습니다. 답답하면 새 세션을 여세요` | 규칙만 있고 이유가 없어 "왜"를 화면이 답하지 못한다 |
| b | `모델은 세션 안에서 바꾸지 않습니다 — 답답하면 새 세션. (바꾸면 컨텍스트 전체를 다시 씁니다)` | 한 줄이 길어 좁은 열에서 두 줄로 접힌다 |
| c | `새 세션 원칙: 모델 고정` | 너무 짧아 처음 보는 사람이 무슨 원칙인지 모른다 |

**추천**: b. 이 자리는 "X로 올리면 $"라는 비용 계산이 있던 자리라, 규칙만 남기면 왜 계산을 걷어냈는지가 화면에서 사라진다. 괄호 절이 그 이유를 한 마디로 대신한다.

#### D-4 `mainModel` · `modelCalls` 처리

| 선택지 | 내용 | 대가 |
|---|---|---|
| a | 스냅숏 `mainModel`만 지우고 `s.modelCalls` 누적은 남긴다 | 아무도 읽지 않는 누적이 세션 객체에 남는다 |
| b | `mainModel`과 `s.modelCalls`를 함께 지운다 | Cache breaks 표의 `model_switch`가 살아 있는데(§2.2 제외) 세션의 모델별 호출 수라는 사실만 사라진다. 되살리려면 누적을 다시 넣어야 한다 |

**추천**: a. `modelCalls`는 모델 비교의 파생물이 아니라 "이 세션이 어느 모델을 몇 번 불렀나"라는 원 사실이고, 대원칙(세션 내 모델 고정)의 위반을 재는 재료라 `model_switch`를 남기기로 한 §2.2 제외와 결이 같다. 비용은 정수 카운터 하나다.

#### D-5 아카이브 실측 고정(SC-11 · SC-12)의 검증 형태

| 선택지 | 내용 | 대가 |
|---|---|---|
| a | `data/fishing`이 있을 때만 도는 조건부 테스트를 커밋한다(`fs.existsSync`로 `skip`) | 아카이브가 없는 환경(공개 저장소 clone)에서는 항상 skip이라 `node --test` 결과만 보고는 검증됐는지 알 수 없다 |
| b | 자동 테스트를 두지 않고 `curl /api/state`의 값을 do §3에 기록한다 | 회귀를 잡지 못한다. 다음 사이클에서 활성시간 식을 건드려도 아무 테스트가 울지 않는다 |

**추천**: a. `data/`는 `.gitignore`에 있어 픽스처를 커밋할 수 없지만 이 머신에서는 회귀를 잡아야 한다. skip 여부가 `node --test` 출력에 그대로 찍히므로 do §3에 "skip 아님"까지 남기면 b의 기록성도 함께 얻는다.

**server.js — 신설**

```js
// KST 05:00 일 경계. KST(+9)에서 05시를 빼면 UTC 자정이 된다.
const DAY_SHIFT = 4 * 3600e3;
const dayKey = ts => new Date(ts + DAY_SHIFT).toISOString().slice(0, 10);

// 세션 필드 (session() 초기값에 추가)
activeMs: 0,          // 활성시간 합계(ms)
days: {},             // 'YYYY-MM-DD' -> { activeMs, cost }

// 파일 필드 (readFile의 초기값과 truncate 리셋 양쪽에 추가)
grp: null,            // { id, prevTs, lastTs, cost } — 진행 중인 requestId 그룹
actPrevTs: 0,         // 직전의 시각 있는 top-level 이벤트 시각

function addDay(s, ts, ms, cost) {
  const k = dayKey(ts);
  const b = s.days[k] || (s.days[k] = { activeMs: 0, cost: 0 });
  b.activeMs += ms; b.cost += cost;
}

// 열린 그룹을 확정한다. 중간에 끊겨도 다음 그룹의 prevTs가 여기 lastTs가 되어 합이 보존된다.
function flushGroup(f) {
  const g = f.grp; if (!g) return;
  f.grp = null; f.actPrevTs = g.lastTs;
  const s = sessions.get(f.sessionId); if (!s) return;
  const ms = Math.max(0, g.lastTs - g.prevTs);
  s.activeMs += ms; addDay(s, g.lastTs, ms, g.cost);
}

// handleRecord에서 부른다. 활성시간에서 사이드체인을 제외한다(D-7).
function trackActive(f, d, ts) {
  if (f.isSub || d.isSidechain === true) return;
  if (!ts) return;                          // 시각 없는 top-level 이벤트는 영향이 없다 (SC-8)
  const m = d.message;
  const real = d.type === 'assistant' && m && m.usage && m.model !== '<synthetic>';
  if (!real) { flushGroup(f); f.actPrevTs = ts; return; }
  const id = d.requestId || m.id;           // 아카이브에서 requestId 결측은 <synthetic>뿐이다
  if (f.grp && f.grp.id === id) { f.grp.lastTs = ts; return; }
  flushGroup(f);
  f.grp = { id, prevTs: f.actPrevTs || ts, lastTs: ts, cost: 0 };
}

// 폴더 전체 합계. sessions 맵 전체를 돈다(D-9).
function folderTotals() {
  const days = {}; let activeMs = 0, cost = 0;
  for (const s of sessions.values()) {
    activeMs += s.activeMs;
    for (const k of Object.keys(s.days)) {
      const b = s.days[k], t = days[k] || (days[k] = { activeMs: 0, cost: 0 });
      t.activeMs += b.activeMs; t.cost += b.cost; cost += b.cost;
    }
  }
  return { activeMs, cost, days };
}
```

**server.js — 호출 지점**

|---|---|
| `handleRecord` 266행(`firstTs`/`lastTs` 갱신) 바로 뒤, `switch` 진입 전 | `trackActive(f, d, ts);` |

const hrs = ms => { const h = ms / 3600e3; return h >= 1 ? h.toFixed(1) + 'h' : Math.round(ms / 60e3) + 'm'; };
const perHr = (cost, ms) => ms > 0 ? usd(cost / (ms / 3600e3)) : '-';

// Cost 카드의 연비 3칸: 이 세션 · 오늘(폴더) · 평소(폴더 전체). 주 숫자는 시간당 비용이다.
function fuelCells(s) {
  const fo = state.folder; if (!fo) return '';
  const today = fo.days[dayKey(Date.now() + clockSkew)] || { activeMs: 0, cost: 0 };
  const cells = [
    ['이 세션', perHr(s.cost, s.activeMs), `활성 ${hrs(s.activeMs)}`],
    ['오늘', perHr(today.cost, today.activeMs), `활성 ${hrs(today.activeMs)} · ${usd(today.cost)}`],
    ['평소 (이 폴더)', perHr(fo.cost, fo.activeMs), `활성 ${hrs(fo.activeMs)}`],
  ];
  return `<div class="whatif" title="활성시간 = 모델이 실제로 돌던 시간만 합산 · 대기와 생각 시간은 빠진다. 하루 경계는 KST 05시">`
    + cells.map(([l, v, d]) => `<div><div class="wl">${l}</div><div class="wv">${v}/h</div><div class="wd">${d}</div></div>`).join('')
    + `</div>`;
}

// 컨텍스트 카드에서 모델 전환 칸이 있던 자리 (D-3)
function principleLine() {
  return `<div class="sub" style="margin-top:10px">모델은 세션 안에서 바꾸지 않습니다 — 답답하면 새 세션. <span style="color:var(--dim)">(바꾸면 컨텍스트 전체를 다시 씁니다)</span></div>`;
}
