## 1. 목적

모델별 비교라는 프레임을 화면에서 걷어내고 그 자리에 연비 계기판을 올린다. 사용자가 세운 대전제는 "세션 내 모델 변경 금지가 대원칙이고, 답답하면 새 세션을 여는 것이 원칙이다"이다. 이 원칙 아래서는 v0.1.3 · v0.1.4가 다듬어 온 모델 비교 카드("fable이었다면 2.04×")와 컨텍스트 카드의 모델 전환 사다리("effort 올리기 → 옆 세션 상담 → 압축 후 전환")가 둘 다 "바꾸면 얼마"를 묻는 화면이라 원칙과 어긋난다. 백로그 205b21ca가 남긴 "절대 증감액 대신 상대 배수"와 v0.1.4 report §3.1 이월(배수를 주 숫자로), §3.4의 fable/opus 역전 설명 부재는 카드와 함께 폐기한다. 대신 c5ea3663의 "총액만 보여서 '빠르게 태우는 중'인지 '천천히 쓰는 중'인지 알 수 없다"를 사용자가 다시 정의한 형태로 올린다. 세션의 활성시간당 비용 옆에 KST 05시 경계의 하루 누적 활성시간당 비용과 루트 폴더 전체 활성시간당 비용을 나란히 놓아 지금 세션과 오늘의 연비를 평소와 비교한다. 활성시간의 정의는 사용자가 확정했다. isSidechain을 제외하고, assistant 줄을 requestId로 그룹핑한 뒤, 각 그룹의 last_ts에서 직전 top-level 이벤트 시각을 뺀 값을 합산한다. 로컬 툴 대기와 사용자 사고시간은 이 정의에서 자동으로 빠진다. 여기에 검수 중 사용자가 더한 두 건이 붙는다. 아바타 밑에 모델명 말풍선을 두는 것과, 컨텍스트 카드의 "지금 사고 나면 $X" 줄을 지우는 것이다. 후자는 v0.1.4 D-11이 TTL 카드의 "깨뜨리면 $X"와 나란히 남기기로 한 결정의 번복이다.

### 2.2 제외

- `PRICE` 표와 `price()` 삭제 — 사용자 지시의 폐기 목록에 `PRICE`가 있었으나 F-3대로 실비 · 손실 · 사고 비용 계산 전부가 이 표를 읽는다. 질문 1 답(2026-09-05)으로 폐기하지 않는다.
- `model_switch` 브레이크 원인, 습관표의 "모델 바꾸기" 행, Cache breaks 표의 원인 색 — 대원칙(세션 내 모델 변경 금지)의 위반을 재는 계기이므로 남긴다.
- 컨텍스트 그래프의 모델별 선 색(`col`) — 모델을 비교하는 것이 아니라 시계열에 실제 모델을 표시하는 것이다.
- P2-1(ca294ce0) 그래프 x축 유휴시간 제거 — 백로그가 "P1-6의 런타임 계산과 동일한 유휴 판정 기준"을 요구하지만 그래프는 이번이 아니다. 이번 정의를 그래프가 재사용할 수 있도록 서버 값으로 남기는 데서 멈춘다.
- 유휴 포함/제외 토글 — c5ea3663의 "있으면 더 좋다". 지시 문장에 없다.
- 분당 비용 — c5ea3663 원문의 "분당 $0.09". 지시 문장이 시간당만 말한다.
- TTFT(첫 토큰까지 시간) 표시 — F-6대로 이 데이터에서는 뽑을 수 없다.
- 좁은 화면 배치 되돌리기 — CSS 99~105행의 Cost ↔ 캐릭터 스왑(P3-1)은 "Cost 카드의 3칸 whatif 그리드가 넓은 열을 필요로 한다"가 근거였고 #2 뒤에는 그 근거가 사라지지만, 배치는 그대로 둔다. 표시 정합성 묶음과 함께 본다.
- 표시 정합성 묶음(3a1e2df9 · 36a5e2bc · 5fcab11d · db0fad38) · 브릿지 재접속 원인 분류(8d12b274) · `deferred_tools_delta` 신필드(b2936bbd) — v0.1.4 report §7의 다른 후보.
- 실측값의 디스크 영속 저장 · 아카이브 원본을 픽스처로 커밋 · CI 도입 · `package.json` — v0.1.4 §2.2 · RULE.md 예외 1 · 2 · 4.
