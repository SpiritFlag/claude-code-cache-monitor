# 🔍 Cache Monitor for Claude Code v0.1.1 업데이트 안내

**릴리즈 날짜:** 2026-09-05

모험가 여러분, 안녕하십니까. 초기 공개 이후 첫 정식 업데이트를 전해 드립니다.

이번 패치는 **"캐시가 왜 깨졌는가"를 가려내는 판정부**를 손봤습니다. 없던 원인 두 가지를 새로 알아보게 되었고, 손실이 아닌 것을 손실로 세던 계산을 바로잡았으며, 나중에 되짚어 볼 수 있도록 브레이크마다 근거를 남기기 시작했습니다.

---

## ✨ 기능

- **세션 재개**를 캐시 깨짐의 원인으로 새로 알아봅니다. 이전에는 중단했던 작업을 이어서 시작할 때 생긴 캐시 손실이 "원인 불명"으로 밀려났지만, 이제는 재개로 정확히 표시됩니다.
- **브레이크포인트 이동**을 새 원인으로 구분합니다. 캐시 기준점이 자리를 옮기며 일부를 다시 쓰는 것은 정상 동작이므로, 원인으로는 보여 드리되 손실로는 세지 않습니다.
- 대화 이력이 다시 기록된 구간의 재개 흔적을 중복으로 세지 않습니다. 재개 뒤 처음 맞는 캐시 깨짐이 엉뚱하게 재개 탓으로 기록되던 문제가 사라졌습니다.
- 캐시 깨짐 기록마다 **판정 근거를 함께 남깁니다.** 직전·현재 호출의 토큰 구성, 캐시 읽기 증감, 컨텍스트 증감, 호출 간격, 프리픽스 보존 여부 등이 상세 정보에 담깁니다. 원인 표시가 미덥지 않을 때 무엇을 보고 그렇게 판정했는지 되짚어 볼 수 있습니다.

## 🛠️ 버그수정

- **손실 계산이 부풀려지던 오류를 바로잡았습니다.** 직전 호출에서 애초에 캐시에 들어가지 못한 몫까지 "다시 쓴 토큰"으로 세고 있었습니다. 이제 실제로 캐시에 남아 있던 부분만 기준으로 삼습니다.
- 브레이크포인트 이동과 압축이 **연속 무사고 기록을 끊지 않습니다.** 정상 동작 때문에 캐릭터의 연속 기록이 초기화되던 일이 없어졌습니다.
- 손실에서 빼야 할 금액을 화면에서 다시 한 번 빼던 구조를 정리해, 어느 값도 두 번 빠지지 않습니다.

## 🎨 UI/UX

- 습관 순위표에 **"세션 재개"** 항목이 추가되어, 재개로 새어 나간 비용이 다른 습관과 나란히 순위에 오릅니다.
- 순위표 아래 안내 줄이 **"압축·브레이크포인트 이동(정상)은 제외"** 로 바뀌어, 무엇이 손실 집계에서 빠졌는지 건수와 금액으로 함께 보입니다.

## 🙏 마치며

겉모습은 크게 달라지지 않았지만, 화면에 뜨는 숫자를 믿을 수 있게 만드는 작업이었습니다. 잘못 세던 것을 바로잡고, 몰라보던 것을 알아보게 하고, 다음에 되짚을 근거를 남겨 두었습니다.

다만 이번 판정 변화가 실제 한 달치 사용 기록에서 어떤 폭으로 나타나는지는 아직 대조하지 못했습니다. 이번에 심어 둔 판정 근거가 그 확인의 재료가 될 것입니다. 다음 업데이트에서 남은 "원인 불명"들의 정체를 마저 밝혀 오겠습니다. 앞으로도 잘 부탁드립니다.
