# 🧮 Cache Monitor for Claude Code v0.1.3 업데이트 안내

**릴리즈 날짜:** 2026-09-05

모험가 여러분, 안녕하십니까. 이번에는 **"다른 모델이었다면 얼마"** 칸의 숫자를 바로잡았습니다.

두 가지가 겹쳐 있었습니다. 비교에서 빼야 할 모델을 잘못 고르고 있었고, Fable 환산에 옛 단가를 쓰고 있었습니다. 화면이 좁을 때의 배치도 함께 손봤습니다.

---

## 🛠️ 버그수정

- **지금 쓰고 있는 모델이 비교 목록에 그대로 남던 문제를 바로잡았습니다.** 비교 칸은 "이 세션에서 가장 많이 쓴 모델"을 기준으로 자기 자신을 빼고 있었는데, 화면 위쪽과 세션 목록은 "지금 쓰는 모델"을 보여줍니다. 세션 도중에 모델을 바꾸면 이 둘이 어긋나, 방금 바꿔 쓰고 있는 모델이 비교 목록에 남고 정작 비교해야 할 모델이 사라졌습니다. 이제 화면에 표시되는 현재 모델을 기준으로 뺍니다.
- **Fable 환산 금액이 실제보다 크게 높던 문제를 바로잡았습니다.** 캐시를 다시 읽을 때의 값이 옛 단가로 계산되고 있었습니다. 캐시 읽기가 많은 세션일수록 차이가 벌어져, 한 기록에서는 $253.50으로 표시되던 것이 실제로는 $103.32였습니다.
- **캐시 만료가 가까울 때 뜨는 경고에 같은 금액이 두 번 적히던 것**을 한 번으로 줄였습니다. 바로 윗줄에 이미 있는 금액이었습니다.

## 🎨 UI/UX

- **왼쪽 세션 목록을 접을 수 있습니다.** 목록 위의 버튼으로 접으면 그래프와 카드가 그만큼 넓어집니다. 접어 둔 상태는 브라우저가 기억하므로 다시 열어도 그대로입니다.
- **좁은 화면에서의 배치를 정리했습니다.** 창이 좁아지면 위쪽 네 칸이 두 줄로 접히는데, 아랫줄에서 캐릭터와 비용 카드의 자리를 맞바꿨습니다. 비용 카드에는 모델 비교 세 칸이 들어가므로 넓은 쪽이 필요하고, 캐릭터는 좁은 쪽으로 충분합니다.

---

## 🙏 마치며

이번에는 새로 보여 드리는 것 없이, **이미 보여 드리던 숫자 하나를 고치는** 작은 업데이트였습니다. 비교 칸은 어느 모델로 작업할지 정할 때 보는 자리인데 그 숫자가 어긋나 있었으니, 늦게나마 바로잡습니다.

다만 한 세션 안에서 여러 모델을 오간 경우에는 비교 금액이 아직 정확하지 않습니다. 실제로 낸 값은 호출마다 그때의 단가로 쌓이는 반면, 비교 금액은 전체를 한 모델로 환산해 계산하기 때문입니다. 이 부분은 계산 방식을 다시 정하는 일이라 따로 준비하고 있습니다. 앞으로도 잘 부탁드립니다.
