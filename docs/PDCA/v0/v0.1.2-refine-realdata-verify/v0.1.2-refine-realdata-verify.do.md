## 5. 진행 로그

### 세션 1 (2026-09-05)

- 시작: design 확정 상태 확인. do.md 신설. 범위 지정 없어 design §3 전 배치(B-1~B-5)를 design B-1 행의 R-7 지시(사용자 확인을 기다리지 않고 다음 배치로 진행)에 따라 순서대로 진행한다.
- 범위 밖 관찰(report §3.4용): `index.html`의 습관 순위표(`habitsCard`)는 세션 카드를 선택해야 렌더되고 "폴더 전체" 열도 실제로는 `s.byCause` 합이 아니라 `HABITS` 매핑을 통한 세션별 재계산이라, 사용자가 확인한 "제외 안내 줄"(compact·breakpoint_shift 건수)은 폴더 전체 집계가 아니라 세션 단위 값이다. 플랜 SC-3 문구("폴더 전체 손실 금액이 …이고 습관 순위표의 세션 재개가 3건")는 손실 금액은 폴더 전체 API 값(`breakCost` 합)과 맞지만 습관 순위표·제외 줄은 세션 단위 표시라 폴더 전체를 한눈에 보여주는 화면이 없다. 코드는 안 건드림(§2.2 제외).
