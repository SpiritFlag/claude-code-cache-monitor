# 📐 Cache Monitor for Claude Code v0.1.2 업데이트 안내

**릴리즈 날짜:** 2026-09-05

모험가 여러분, 안녕하십니까. 지난 업데이트에서 약속드린 **실사용 기록 대조**를 마치고 돌아왔습니다.

한 달치 실제 작업 기록을 통째로 돌려 지난 판정 변화가 어떤 폭으로 나타나는지 확인했고, 그 과정에서 발견한 **집계 부풀림** 하나를 바로잡았습니다. 원인 분류와 손실 금액은 대조 전후로 한 건도 달라지지 않았습니다.

---

## 🛠️ 버그수정

- **다시 기록된 대화 구간이 두 번 집계되던 문제를 바로잡았습니다.** 작업을 재개할 때 이전 대화 이력이 파일에 다시 쓰이는 경우가 있는데, 그 구간이 통째로 한 번 더 세어지고 있었습니다. 실사용 기록에서는 한 세션의 대화 수가 실제보다 두 배 가까이(204 → 105) 부풀려져 있었습니다.
- 같은 원인으로 **질문 횟수 · 커밋 횟수 · 압축 횟수**도 함께 부풀려지던 것이 바로잡혔습니다. 세션 카드와 습관 순위에 뜨는 숫자가 이제 실제 작업량과 맞습니다.
- 캐시 깨짐마다 남기는 **판정 근거 목록에 같은 항목이 중복으로 쌓이던 것**이 사라졌습니다. 어떤 기록에서는 근거가 11개까지 늘어나 읽기 어려웠지만, 이제 실제로 일어난 6개만 남습니다.

## ✨ 기능

- 진단 도구에서 **특정 세션이나 특정 원인만 골라 볼 수 있습니다.** 이전에는 전체 기록을 모두 훑어야 원하는 몇 건을 찾을 수 있었지만, 이제 보고 싶은 것만 바로 뽑아 볼 수 있습니다.

## 🙏 마치며

이번 업데이트는 새로 보여 드리는 것보다 **이미 보여 드리던 숫자가 맞는지 확인하는 일**에 가까웠습니다. 원인별 건수와 손실 금액은 실사용 기록에서도 흔들리지 않았고, 정상 동작과 손실을 가르는 판정 기준도 한 달치 분포로 다시 재어 그대로 두는 것이 맞다는 결론을 얻었습니다.

다만 남아 있던 "원인 불명" 일곱 건 가운데 셋까지만 실마리를 찾았고, 넷은 지금 기록에 남는 정보만으로는 가려낼 수 없다는 것을 확인했습니다. 무엇이 더 있어야 밝혀낼 수 있는지는 정리해 두었으니, 재료가 갖춰지는 대로 다시 찾아뵙겠습니다. 앞으로도 잘 부탁드립니다.
